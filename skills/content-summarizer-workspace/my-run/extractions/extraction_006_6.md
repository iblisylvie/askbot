# Chunk 6.1 Extraction

## Key Points
- [ ] DiT (Diffusion Transformer) 论文的诞生故事：从被多次拒稿到成为重要突破，揭示了学术评审的随机性和坚持的重要性
- [ ] 反脆弱研究系统：研究者应将挫折（如论文被拒）转化为成长机会，建立能从冲击中受益的系统
- [ ] Cambrian (寒武纪) 项目：多模态大模型研究，探索视觉智能的本质，从 L0 到 L4 的渐进式智能层级
- [ ] 视觉作为视角 (Vision as Perspective)：计算机视觉不仅是任务/领域，而是智能必须解决的一系列问题的总和
- [ ] 语言模型与视觉智能的本质差异：语言是交流工具，视觉是处理连续、高维、有噪声信号的能力，两者解决的问题域不同
