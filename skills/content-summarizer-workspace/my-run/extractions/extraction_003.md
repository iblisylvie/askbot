# Chunk 3 Extraction

## Key Points
- [ ] 研究idea的产生不是坐在那儿想出来的，而是通过探索性实践（exploration）获得的，Kaiming He的研究哲学深刻影响了讲述者的研究方式
- [ ] 好的研究需要1-2个月的探索期，像hacker一样动手实践、复现论文、尝试拓展，从实验中找signal/梯度，而非直接追求从A到B的线性路径
- [ ] 最差的研究是一开始定义的问题和最终发表的论文完全一致，没有任何意外和障碍；最好的研究是在探索过程中不断调整方向、走弯路后形成的
- [ ] 学术界应追求"代表作"（max）而非平均产出，研究是一个"无限游戏"而非有限游戏，研究者像发明家而非运动员，一生只需成功一次即可
- [ ] 当前学术界面临挑战：大厂（OpenAI、Google、Meta）主导了研究方向，学术界被迫跟随大厂发布的范式，失去了定义问题的能力

## Key Quotes
- "这些所有的idea你不能坐在那儿想... 如果你要想出来一个idea，这个idea一定不是一个好的idea"（讲述者转述Kaiming He的观点）
- "探索中的idea才是属于你的idea... 一开始你想的这个idea不是你的idea"（讲述者）
- "最差的研究是一开始你定义好的一个问题... 最后你发了一篇论文，这个论文的idea跟你一开始想的idea完全一致"（讲述者）
- "researcher更像一个发明家，说你这辈子真的只需要成功一次就够了"（讲述者）

## Questions Raised
- 在竞争激烈的学术环境中，如何保持探索心态而非急于追赶最前沿？
- 学术界如何重新获得定义问题的能力，而非跟随大厂的研究方向？
