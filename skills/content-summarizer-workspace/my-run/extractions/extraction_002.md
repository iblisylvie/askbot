# Chunk 2 Extraction

## Key Points
- [ ] 博士生期间的实习经历和对DeepMind组织的观察：实习生体验了DeepMind独特的管理模式，包括PM协调、working group机制，以及从自下而上探索到自上而下执行的组织转变
- [ ] 表征学习(Representation Learning)是深度学习的核心：讲述者将自己定位为"做表征学习的人"，认为这是AI领域永恒的主题，而非像NAS(Neural Architecture Search)那样的短暂热点
- [ ] 从博士到职业选择的经历：包括拒绝OpenAI的offer选择FAIR，以及与Ilya Sutskever的两次电话交流(2018年和2024年)
- [ ] 影响讲述者的重要人物：何凯明、Young(杨立昆/李飞飞)、李飞飞等，强调"人"在学术选择中的重要性
- [ ] 自监督学习与对比学习的发展：讲述MoCo(Momentum Contrast)工作的诞生背景，以及凯明对Scaling的早期洞察(2018-2019年)
