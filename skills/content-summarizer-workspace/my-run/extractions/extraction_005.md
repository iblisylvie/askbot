# Chunk 5 Extraction

## Key Points
- [ ] Research taste（研究品味）是一种难以明确定义的内在审美，涉及对真理的求索和打破表象看本质的能力
- [ ] 凯明（Kaiming He）通过《金刚经》传达研究哲学："凡所有相皆是虚妄"，强调透过论文表象追问背后实质
- [ ] 优秀研究者应具备质疑精神，不沉迷于论文接受、外界名声等"虚像"
- [ ] 写作能力和细节打磨是research taste的重要组成部分，凯明会在deadline前一个月完成论文并反复打磨
- [ ] ConvNeXt项目通过质疑Vision Transformer中的soft attention机制，发现架构设计比注意力机制更重要
- [ ] DiT项目展示了从表征学习转向架构优化的决策过程，以及学术评价中的随机性（被拒稿经历）

## Key Quotes

- "不是因为看见，所以相信；因为相信，所以看见"（访谈者引用本科老师的话，强调信念先于发现）
