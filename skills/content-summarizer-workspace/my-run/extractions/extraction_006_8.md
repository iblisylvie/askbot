# Chunk 6.3 Extraction

## Key Points
- [ ] 世界模型需要从人类感官的高带宽输入（10亿bits/秒）压缩到行为输出的低带宽（10-100 bits/秒），关键在于过滤冗余信息和识别重要内容
- [ ] 训练世界模型面临巨大的数据挑战：一个4个月大的婴儿看过的视频量超过当前最好的大语言模型的训练数据量
- [ ] 创业动机是逃离"中等论文陷阱"——在学术界受资源限制无法将想法转化为真正的突破，同时大厂环境缺乏研究自由度
- [ ] 与Yann LeCun合作创业的核心理念是"反向OpenAI"：不是从互联网下载数据训练模型再推向市场，而是与真实世界中的产业伙伴共建世界模型
- [ ] 公司定位介于纯粹研究实验室和封闭式大模型公司之间，约60-70%像研究实验室，30-40%是前沿探索，强调开放合作而非军备竞赛
