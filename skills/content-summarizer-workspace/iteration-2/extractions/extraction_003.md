# Extraction 003 - Chunk 3

## Key Points

1. **研究探索的范式**: 真正的研究idea不是坐在那儿想出来的，而是通过大量探索（1-2个月）找到的。探索期需要像黑客一样动手去玩、去实验，把研究当作游戏。

2. **梯度即idea**: 研究的核心不是从A点（idea）到B点（paper），而是找到"梯度"（gradient）——在探索过程中发现的信号。好的结果和坏的结果都是好的结果，意外和惊喜才是最宝贵的。

3. **研究的非线性特征**: 时间上非线性（可能需要到第五个月才突然找到方向），结果上非线性（职业生涯影响不是线性的，一篇真正好的工作会瞬间把impact冲到顶点）。

4. **学术界vs工业界的游戏性质**: 学术界应该是一个"无限游戏"（这辈子成功一次就够了），但现在被大厂带成了"有限游戏"（追赶、复现、抢占先机）。

5. **定义问题的能力**: 真正厉害的研究者是能够定义问题的人，失去这种能力就失去了创新能力。

## Intellectual Framework

### Methodology
1. **研究周期规划**: 6个月一个周期（1-2个月探索 + 2-3个月深化实验 + 1-2个月写作）
2. **探索期活动**: 
   - 推公式
   - 读论文
   - 动手写代码（复现、拓展）
   - 找信号（gradient）
3. **评估标准**: 最差的研究是一开始idea和最后论文完全一致（说明没有探索）；最好的研究是经历了弯弯绕绕才到达终点

### Philosophy
- **研究是无限游戏**: 不像下棋或运动（有限游戏，取决于最差的一步），研究像发明——这辈子成功一次就够了
- **探索即收获**: 探索的过程本身就是积累，哪怕最后没有直接产出
- **意外即财富**: 令人惊讶的observation是研究中最幸福的事情
- **定义问题 > 解决问题**: 能够定义问题的人才是真正的创新者

### Influences
- **何凯明的研究哲学**: 梯度即idea，探索即研究
- **Bill Freeman的图表**: 研究工作对职业生涯的非线性影响曲线
- **学术界传统定位**: 制定游戏规则、定义方向，而非追赶

### Evolution
- **从学生到导师**: 现在会告诉学生"增加输入"、"给自己足够时间和空间去探索"
- **从跟随到反思**: 通过Google经历意识到应该做工业界不做的事情
- **从追求数量到追求质量**: 意识到只需要一篇真正有价值的工作
