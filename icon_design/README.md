# anyseek — Brand Identity (v2)

> 混沌中找低维结构 · 路漫漫，求索不止

**anyseek** 是一个聚焦 AI 进展追踪与教育的内容品牌。Logo 的核心主张是 **涌现（Emergence）**：从混沌点云中自然生长出一条数学严谨的对数螺旋——这条螺旋本身就是"低维结构"的最朴素证明。

## 设计概念

- **核心隐喻**：对数螺旋（r = a·e^(b·θ)，b ≈ 0.28，接近黄金比例），约 2 圈，由内向外生长
- **三层叙事**：混沌散点（背景纹理）→ 螺线主体（已发现的结构）→ 开放端点（仍在求索）
- **节点节奏**：5 个圆点沿螺线由内到外递增，象征认知/内容的累积
- **端点**：外侧最大、最亮的实心圆 + 一圈光晕环，表达"当下进行时"
- **主色**：珊瑚橙 `#E07A5F`，在黑/白底上均可见
